## 專案狀態

目前版本為 `1.0.0-prerelease`。核心 MVP 已包含飲水記錄、習慣封存與恢復、月曆補登、streak 統計、近似時間提醒、即時主題切換及完整 adaptive icon。

目前不包含帳號登入、雲端同步、跨裝置備份、桌面小工具及健康平台整合。
